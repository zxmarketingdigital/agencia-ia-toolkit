Toolkit Agência IA

12 ferramentas pra você entregar Agência IA aos seus 3 primeiros clientes

Skills do Claude Code + dashboards HTML standalone. Você instala em 15min e usa hoje mesmo com seu primeiro cliente.

▸ Instalar em 15min

▸ Quickstart — instale em 15min

▾
1

Clone o repositório

Pré-requisito: git instalado.

git clone https://github.com/zxmarketingdigital/agencia-ia-toolkit
2

Rode o instalador

Copia as 12 skills pra ~/.claude/skills/ e abre os 2 dashboards.

cd agencia-ia-toolkit && ./install.sh
3

Use a primeira skill

Abra o Claude Code em qualquer pasta e digite o comando abaixo. Comece pelo diagnóstico do seu próximo cliente.

/diagnostico-cliente
