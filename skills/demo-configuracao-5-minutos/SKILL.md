# Demo — Configuração em 5 Etapas (Timer ao Vivo)

Mostra o setup do agente passo a passo com cronômetro, reforçando a promessa dos 15 minutos.

## Uso

```bash
python3 ~/.claude/skills/demo-configuracao-5-minutos/run.py
```

## Observações

- **Rodar via Bash direto na sessão Claude Code** — é assim que o Rafael grava os anúncios
- Só usar Terminal.app se o Rafael pedir explicitamente ("rodar no terminal", "gravar do terminal")
- Fonte recomendada (se Terminal): JetBrains Mono 14px, fundo #0a0a0f
- Duração total: ~35 segundos
- Produto: Agente IA WhatsApp em 15 Minutos
